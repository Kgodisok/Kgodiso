# Kgodiso — personal website

A responsive personal portfolio built with React and Vite.

## Run locally

```sh
npm install
npm run dev
```

## Personalize

- Update the introduction and about copy in `src/App.jsx`.
- Replace the sample projects in the `projects` array in `src/App.jsx`.
- Add photos to `public/gallery/`, then set each `image` value in the `gallery` array in `src/App.jsx` to its public path (for example, `/gallery/photo-01.jpg`).
- Change `hello@example.com` to your email address.
- Update the title and description in `index.html`.

The project cards are visual placeholders until you add your own work and links.
