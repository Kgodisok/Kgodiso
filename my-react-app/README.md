# Personal photo gallery

A responsive, animated personal photo gallery built with React and Vite.

## Run locally

```sh
npm install
npm run dev
```

## Production build

```sh
npm run build
npm run preview
```

The deployable static site is generated in `dist/`. Publish the contents of that folder with your hosting provider.

## Personalize

- Add photos to `public/gallery/`, then set their paths and descriptions in the `photos` array in `src/App.jsx`.
- Update the page title and description in `index.html` if you want different wording.
